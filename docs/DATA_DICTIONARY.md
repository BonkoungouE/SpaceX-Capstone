# Data dictionary and lineage

## Historical model inputs

| Column | Meaning / handling |
| --- | --- |
| FlightNumber | Sequential launch index in the modeling sample |
| Date | Launch date, ISO format |
| BoosterVersion | Rocket family, Falcon 9 in the filtered sample |
| PayloadMass | Payload mass in kg, missing values imputed in course snapshot |
| Orbit | Mission orbit label |
| LaunchSite | Launch site label in the 90-row snapshot |
| Outcome | Landing-success state and landing type combined |
| Flights | Number of flights associated with the core at the mission |
| GridFins, Reused, Legs | Binary launch/core attributes |
| LandingPad | Landing-pad identifier, missing when not used or unavailable |
| Block | Core generation indicator |
| ReusedCount | Core reuse count supplied by the resource snapshot |
| Serial | Core identifier |
| Longitude, Latitude | Launch-site coordinates in degrees |
| Class | Course target, 1 for outcomes outside the explicitly listed bad outcomes |

Bad outcomes: `False ASDS`, `False Ocean`, `False RTLS`, `None ASDS`, `None None`.
`True Ocean` counts as positive under the lab's convention.

## Feature matrices

- `data/processed/dataset_part_3.csv`: 80 columns generated by explicitly one-hot encoding Orbit, LaunchSite, LandingPad and Serial. Binary attributes remain one numeric column each.
- `data/reference/dataset_part_3.csv`: supplied course model input, 83 columns. It replaces each of the three binary attributes with two dummy columns.
- The ML notebook uses the reference matrix, so its execution reproduces the report's metrics. The difference is documented rather than hidden through overwriting a source file.

## SQL sample

`data/raw/Spacex.csv` contains 101 records with labels such as `Launch_Site`, `Mission_Outcome`, `Landing_Outcome`, `Booster_Version` and `PAYLOAD_MASS__KG_`. Customer and exact booster-version filters define the queried populations. Mission outcome and first-stage landing outcome are different concepts.

## Interactive sample

`spacex_launch_geo.csv` and `spacex_launch_dash.csv` contain 56 launches with a `class` indicator. The geographic file adds `Lat` and `Long`. The Dash file adds `Booster Version Category`. Site labels distinguish CCAFS LC-40 from CCAFS SLC-40 in this sample.

## Scraped dataset

`data/processed/spacex_web_scraped.csv` contains 121 rows extracted from the archived Wikipedia HTML. Its names, string-valued payload masses and outcome taxonomy differ from the model inputs. A join, cleaning policy and reconciliation would be required before integrating the two sources.
